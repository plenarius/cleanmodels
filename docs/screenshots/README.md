# Screenshots

Images used in the README. They are renderings of real terminal output from cleanmodels v4.2.1, taken
from the build the release was cut from: each command was run in a pseudo-terminal with colours on, and
the resulting screen was drawn as a PNG. The title bar and the `models $` prompt are drawn by the script;
the commands and everything they print are real.

The models are files from `tests/fixtures/oracle/ascii`, plus a one-line text file standing in for a
non-model. To redo one, run the command in a terminal of about 100 to 120 columns and capture it; the
wording of errors and hints is part of the interface, so re-take the images when it changes.
